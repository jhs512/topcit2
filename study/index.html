01 · 공부를 시작하기 전에

교재와 핵심노트 활용하기

  1. 출제기준으로 범위를 확인합니다. 오늘 공부할 항목을 출제기준에서 고릅니다. 보관 교재와 현행 출제기준의 범위가 완전히 같다고 가정하지 않습니다.
  2. 교재의 작은 단원을 읽습니다. 교재에서 관련 목차와 본문을 찾고 개념 한두 개에 집중합니다. 용어, 목적, 사용 조건을 확인합니다.
  3. 핵심노트와 사례에서 실제 사용 상황을 확인합니다. 핵심노트는 자체 실무 해설입니다. 관련 사례를 읽으며 어떤 선택이 왜 필요한지 생각합니다.
  4. 답을 가리고 스스로 풉니다. 문제에서 선택 이유를 설명하고, 서술·수행 과제는 손으로 답을 만듭니다. 모르면 해당 교재 부분으로 돌아갑니다.

핵심노트 160개가 시험 범위 전체를 대신하지는 않습니다. 이 사이트의 문제는 자체 연습문제이며, 8개 과목에 총 3,000문항을 제공합니다. 전체 시험의 네 영역 배점 비율로 연습량을 나눴으며, 코드·SQL·규칙의 조건을 바꾼 연습 변형을 포함합니다. 과목 안의 세부 주제 비중까지 실제 시험과 같지는 않습니다. 교재의 확인 과제와 공식 샘플문제도 함께 활용하세요.

02 · 추천 학습법

교재를 열고 Gemini Live로 대화하세요.

가능하면 텍스트 채팅보다 Gemini Live를 우선 사용하세요. 읽다가 막히면 바로 말로 질문하고, 이해한 뒤에는 내 말로 설명하며 확인합니다. 채팅은 Live를 시작하기 전 페이지를 읽게 하거나, 말하기 어려운 상황에서 보조로 사용합니다.

  1. Chrome에서 이 사이트의 HTML 교재를 엽니다. 교재 목록에서 책을 선택하고 오늘 읽을 단원을 화면에 표시합니다.
  2. 브라우저 상단의 ‘Gemini에게 물어보기’를 엽니다. 교재 탭이 공유 대상으로 잡혔는지 확인합니다. 질문할 단원 제목과 화면의 페이지 번호를 말해 범위를 좁힙니다.
  3. Live를 켜기 전에 채팅에 메시지를 한 번 보냅니다. 안녕처럼 아무 메시지나 입력해 대화를 시작하고, Gemini가 공유한 웹페이지를 읽은 뒤 진행하세요. 필요하면 “이 페이지의 제목과 지금 읽을 단원을 확인해 줘”라고 물어 페이지 내용을 확인했는지 점검합니다.
  4. 페이지 내용을 확인한 뒤 ‘Live로 대화하기’를 누릅니다. 처음에는 설정 안내를 따르고 마이크·스피커 사용을 허용합니다. “이 문장에서 말하는 의미가 뭐야?”처럼 막힌 부분부터 묻습니다.
  5. 설명을 들은 뒤 교재를 가리고 답합니다. 내가 이해한 뜻과 예시를 말한 다음, 빠진 조건이나 잘못된 부분을 확인합니다.
  6. 마지막에는 교재와 대조합니다. Gemini가 참고한 단락을 확인하고, 교재의 설명과 추가 예시를 구분합니다. 페이지를 제대로 읽지 못하면 채팅에 필요한 문단을 붙여 넣어 내용을 확인시킨 뒤 Live 대화를 이어갑니다.

탭 공유와 사용 조건: Google 공식 Chrome의 Gemini 안내. 음성 대화 시작 방법: Google 공식 Live 안내.

뜻을 풀어서 듣기

헷갈리는 개념 비교하기

“인증과 권한 검사가 어떻게 달라? 같은 상황에서 각각 무엇을 확인하는지 설명하고, 내가 구분할 수 있는 질문을 하나씩 해 줘.”

내 설명을 점검받기

“이제 내가 설명할게. 먼저 내 답을 듣고, 맞는 부분과 빠진 조건을 교재 내용에 비춰 짚어 줘.”

정답 대신 힌트 받기

“바로 정답을 말하지 말고, 다음에 무엇을 생각해야 할지 힌트 하나만 줘. 내 답을 기다려 줘.”

04 · 함께 쓰면 좋은 방법

듣기에서 끝내지 않는 여섯 가지 방법

책을 덮고 1분 설명

정의, 필요한 이유, 예시를 자료 없이 말합니다. 말이 막힌 부분만 다시 읽습니다. 혼자라면 녹음하거나 빈 종이에 적어도 됩니다.

날짜를 띄워 다시 풀기

배운 다음 날, 3일 뒤, 1주 뒤에 짧게 다시 묻습니다. 이 간격은 시작용 제안이며 잘 기억하면 늘리고 자꾸 틀리면 줄입니다.

오답을 원인으로 분류

용어를 몰랐는지, 조건을 놓쳤는지, 계산이나 적용에서 틀렸는지 적습니다. 해설을 복사하기보다 다음에 구분할 기준을 한 문장으로 남깁니다.

다른 개념과 섞어서 비교

인증과 권한, 백업과 복구처럼 가까운 개념을 함께 묻습니다. 뜻을 각각 외우는 것에 더해 어떤 상황에서 어떤 개념을 적용할지 설명합니다.

작은 결과를 직접 만들기

짧은 코드, 조회문, 구성도, 작업 순서처럼 눈으로 확인할 결과를 만듭니다. 먼저 예상한 뒤 실행하거나 해설과 비교합니다. Gemini Live에는 완성 답보다 막힌 단계의 힌트를 말로 요청합니다.

음성 읽기(TTS)와 서로 설명하기 활용

사이트의 TTS로 핵심노트를 듣다가 멈추고 다음 내용을 설명합니다. 동료와는 질문하는 사람과 답하는 사람을 번갈아 맡습니다. 이동 중 듣기는 보조 복습으로 쓰고 직접 풀 시간은 따로 남깁니다.

간격을 둔 학습, 퀴즈로 기억을 꺼내는 연습, 설명을 요구하는 질문은 미국 교육과학연구소 IES의 학습 지침을 참고했습니다. 이 페이지의 구체적인 시간·복습 간격은 자체 제안입니다.
