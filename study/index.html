01 · 공부를 시작하기 전에

교재와 핵심노트 활용하기

  1. 출제기준으로 범위를 확인합니다. 오늘 공부할 항목을 출제기준에서 고릅니다. 보관 교재와 현행 출제기준의 범위가 완전히 같다고 가정하지 않습니다.
  2. 교재의 작은 단원을 읽습니다. 교재에서 관련 목차와 본문을 찾고 개념 한두 개에 집중합니다. 용어, 목적, 사용 조건을 확인합니다.
  3. 핵심노트와 사례로 연결합니다. 핵심노트는 자체 실무 해설입니다. 관련 사례를 읽으며 어떤 선택이 왜 필요한지 생각합니다.
  4. 답을 가리고 스스로 풉니다. 문제에서 선택 이유를 설명하고, 서술·수행 과제는 손으로 답을 만듭니다. 모르면 해당 교재 부분으로 돌아갑니다.

핵심노트 160개가 시험 범위 전체를 대신하지는 않습니다. 이 사이트의 문제는 자체 연습문제이며, 현재 01·02 과목은 문제 준비 중입니다. 해당 과목은 교재의 확인 과제와 TOPCIT 공식 홈페이지의 학습자료·샘플문제로 보완하세요.

02 · 추천 학습법

교재를 열고 Gemini에게 입으로 물어보세요.

읽다가 모르는 표현을 만나면 대화를 통해 풀어 보고, 이해한 뒤에는 내가 설명하는 쪽으로 역할을 바꿉니다. 긴 요약을 듣는 것보다 한 개념을 질문하고 다시 설명하는 방식으로 사용해 보세요.

  1. Chrome에서 이 사이트의 HTML 교재를 엽니다. 교재 목록에서 책을 선택하고 오늘 읽을 단원을 화면에 표시합니다.
  2. 브라우저 상단의 ‘Gemini에게 물어보기’를 엽니다. 교재 탭이 공유 대상으로 잡혔는지 확인합니다. 질문할 단원 제목과 화면의 페이지 번호를 말해 범위를 좁힙니다.
  3. ‘Live로 대화하기’를 눌러 말로 질문합니다. 처음에는 설정 안내를 따르고 마이크·스피커 사용을 허용합니다. “이 문장에서 말하는 의미가 뭐야?”처럼 막힌 부분부터 묻습니다.
  4. 설명을 들은 뒤 교재를 가리고 답합니다. 내가 이해한 뜻과 예시를 말한 다음, 빠진 조건이나 잘못된 부분을 확인합니다.
  5. 마지막에는 교재와 대조합니다. Gemini가 참고한 단락을 확인하고, 교재의 설명과 추가 예시를 구분합니다. 페이지를 제대로 읽지 못하면 필요한 문단만 붙여 넣어 질문합니다.

탭 공유와 사용 조건: Google 공식 Chrome의 Gemini 안내. 음성 대화 시작 방법: Google 공식 Live 안내.

뜻을 풀어서 듣기

“지금 교재의 이 단락을 쉬운 말로 설명해 줘. 먼저 왜 필요한지, 다음에 용어의 뜻, 마지막에 쇼핑몰 예시를 들어 줘.”

헷갈리는 개념 비교하기

“인증과 권한 검사가 어떻게 달라? 같은 상황에서 각각 무엇을 확인하는지 설명하고, 내가 구분할 수 있는 질문을 하나씩 해 줘.”

내 설명을 점검받기

“이제 내가 설명할게. 먼저 내 답을 듣고, 맞는 부분과 빠진 조건을 교재 내용에 비춰 짚어 줘.”

정답 대신 힌트 받기

“바로 정답을 말하지 말고, 다음에 무엇을 생각해야 할지 힌트 하나만 줘. 내 답을 기다려 줘.”

05 · 함께 쓰면 좋은 방법

듣기에서 끝내지 않는 여섯 가지 방법

책을 덮고 1분 설명

정의, 필요한 이유, 예시를 자료 없이 말합니다. 말이 막힌 부분만 다시 읽습니다. 혼자라면 녹음하거나 빈 종이에 적어도 됩니다.

날짜를 띄워 다시 풀기

배운 다음 날, 3일 뒤, 1주 뒤에 짧게 다시 묻습니다. 이 간격은 시작용 제안이며 잘 기억하면 늘리고 자꾸 틀리면 줄입니다.

오답을 원인으로 분류

용어를 몰랐는지, 조건을 놓쳤는지, 계산이나 적용에서 틀렸는지 적습니다. 해설을 복사하기보다 다음에 구분할 기준을 한 문장으로 남깁니다.

다른 개념과 섞어서 비교

인증과 권한, 백업과 복구처럼 가까운 개념을 함께 묻습니다. 뜻을 각각 외우는 것에 더해 어떤 상황에서 어떤 개념을 적용할지 설명합니다.

작은 결과를 직접 만들기

짧은 코드, 조회문, 구성도, 작업 순서처럼 눈으로 확인할 결과를 만듭니다. 먼저 예상한 뒤 실행하거나 해설과 비교합니다. Gemini에는 완성 답보다 막힌 단계의 힌트를 요청합니다.

TTS와 짝 설명 활용

사이트의 TTS로 핵심노트를 듣다가 멈추고 다음 내용을 설명합니다. 동료와는 질문하는 사람과 답하는 사람을 번갈아 맡습니다. 이동 중 듣기는 보조 복습으로 쓰고 직접 풀 시간은 따로 남깁니다.

간격을 둔 학습, 퀴즈로 기억을 꺼내는 연습, 설명을 요구하는 질문은 미국 교육과학연구소 IES의 학습 지침을 참고했습니다. 이 페이지의 구체적인 시간·주차·복습 간격은 자체 제안입니다.

06 · 읽은 양보다 설명할 수 있는 것

매주 세 가지를 확인하세요.

  • 설명: 자료를 보지 않고 개념의 뜻과 쓰는 이유를 말할 수 있습니까?
  • 구분: 헷갈리는 개념과 다른 점, 오답이 틀린 이유를 설명할 수 있습니까?
  • 적용: 처음 보는 상황에서도 근거와 풀이 과정을 적을 수 있습니까?

막히는 항목은 다음 주 첫 복습 대상으로 옮깁니다. 맞힌 문제도 보기의 순서나 상황이 바뀌면 다시 풀어 보세요. 사이트의 ‘완료’ 개수는 학습 기록이며 TOPCIT 예상 점수로 환산할 수 없습니다.

목표가 3수준이므로 객관식 정답 확인에만 머무르지 않습니다. 시험 유형을 확인하고, 조건을 읽어 이유와 과정을 직접 적는 연습을 매일 포함하세요.
