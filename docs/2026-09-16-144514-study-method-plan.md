# 학습방법 메뉴 추가 계획

## 범위

- 목표를 TOPCIT 3수준 이상(시작점 400점)으로 해석하고 학습방법 페이지에 명시한다.
- Chrome의 Gemini 탭 공유 및 Live 음성 질문, 미지원 환경의 대안을 Google 공식 안내로 확인한다.
- 하루 60분, 여덟 주제와 혼합 복습을 포함한 10주 계획을 자체 제안으로 제공한다. 시험 성공이나 예상 점수를 보장하지 않는다.
- 기존 메뉴·홈에 학습방법 링크 추가. 교재·문항·기록은 변경하지 않는다.

## 영향 파일과 순서

1. `study/index.html`, `study/styles.css`: 읽기 → 음성 질문 → 회상 → 풀이 흐름, 다른 학습법, 하루·주차 계획.
2. `shared/site-navigation.mjs`, `.css`, `index.html`, `README.md`: 링크와 늘어난 메뉴의 반응형 배치.
3. PC·태블릿·모바일, 키보드 메뉴, 표 스크롤, TTS, 내부 링크를 확인한다.
4. 커밋·푸시 후 Pages 배포와 공개 페이지를 확인한다.

## 근거와 구분

- TOPCIT 공식 소개: https://www.topcit.or.kr/introduction/topcit.do — 3수준 시작 400점, 시험 150분. 오래된 FAQ에는 다른 상한 값이 있어 불필요한 상한 숫자는 인용하지 않았다.
- Google 탭 공유/조건: https://support.google.com/gemini/answer/16283624?hl=ko
- Google Live: https://support.google.com/gemini/answer/16363185?hl=ko
- IES 학습 지침: https://ies.ed.gov/ncee/wwc/practiceguide/1 — 간격 학습·퀴즈·설명 질문. 하루 시간, 10주, 다음 날/3일/1주 간격은 자체 제안.
- 사이트 문항 구성 확인: 01·02는 준비 중. 해당 과목을 사이트 객관식만으로 공부하도록 안내하지 않는다.
- 교재 링크는 기존 자체 HTML 교재로 연결한다. 특정 내용의 페이지를 추정하지 않는다.

## 검증 결과

- 1440·1101·1024·768·390·320px에서 홈 진입, 현재 메뉴 표시, 목차 이동, 10주/60분 표, 접힌 안내, TTS와 키보드 메뉴를 확인했다.
- 본문 내부 링크의 HTTP 성공, 페이지·메뉴 가로 넘침 없음, 브라우저 오류 없음 확인.
- 메뉴 항목 증가에 맞춰 모바일 메뉴 전환점을 1100px로 조정했다.
- 공개 배포 후 학습방법 페이지와 메뉴를 다시 확인한다.
