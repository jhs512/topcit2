## 목표와 확정 범위

교재는 원문, 목차, 여섯 권의 메뉴와 뷰어를 유지한다. 문제·실무 관점·사례 모음은 전체 목록에서 같은 단계의 여덟 주제로 바로 이동한다. 05·06 아래에 하위 메뉴를 두는 이전 초안은 폐기한다.

## 영향과 구현 순서

1. **정책·공통 분류**: AGENTS.md의 하위 단계 지침을 평면 구조로 교체한다. `shared/learning-subjects.mjs`에 여덟 주제와 교재 대응을 두고 모든 학습 메뉴가 공유하게 한다. 작업 중인 `subject-topics.mjs` 및 중첩 메뉴 초안은 제거한다.
2. **공통 메뉴·목록**: `shared/site-navigation.mjs`와 세 메뉴의 목록을 여덟 주제로 맞춘다. 교재 드롭다운은 여섯 권을 유지한다. 준비된 콘텐츠가 없는 주제도 같은 위치에서 준비 상태를 표시한다. 모바일·키보드 이동과 현재 위치 표시를 유지한다.
3. **문제**: `practice/app.mjs`의 화면 분류를 여덟 주제로 바꾸고 각 주제의 경로를 만든다. 05의 4.3 출제기준은 윤리, 나머지는 IT 비즈니스로 분류한다. 06의 프로젝트 문서(4.4.2.2)는 사이트의 테크니컬 커뮤니케이션 주제에, 나머지는 프로젝트 관리에 둔다. 이는 사이트의 학습 분류이며 공식 출제기준 코드와 문항 데이터는 변경하지 않는다. 전체·설명·랜덤 모드, 집계, 히스토리와 초기화는 선택한 주제 기준으로 동작한다.
4. **학습기록·기존 주소**: 문항 ID·revision과 `topcit2-practice-v1` 저장 형식을 유지한다. 기존 `/practice/05/`, `/practice/06/`는 통합 복습의 호환 주소로 유지하고 새 메뉴에서는 사용하지 않는다. 기존 query와 문제 hash, 과거 완료 기록을 확인한다. 집계에서 호환용 묶음을 중복 합산하지 않는다.
5. **실무 관점**: `practical/content.mjs` 원고를 여덟 주제로 재구성한다. 윤리와 테크니컬 커뮤니케이션에 각각 열 개를 집필하고, IT 비즈니스와 프로젝트 관리도 독립된 열 개로 조정한다. 총 80개를 설명·가상 예시·확인 질문으로 제공한다. `scripts/build-practical.mjs`로 생성하고 기존 05·06 주소는 새 주제로 안내한다. 공식 순위나 교재 요약으로 표시하지 않는다.
6. **사례 모음**: 생성기와 분류 원본을 정리해 여덟 주제 목록을 제공한다. 기존 11편은 주제가 모두 IT 비즈니스이므로 05-01로 연결하고 다른 주제는 준비 중으로 표시한다. 기존 사례 ID와 본문·출처는 유지하고 이전 상세 주소에서도 새 주소로 이동할 수 있게 한다. 추가 사례를 작성할 때 분류를 명시할 수 있게 한다.
7. **문서·검증·배포**: README와 관련 작성 지침·분류 설명의 낡은 여섯 과목 표현을 점검한다. 원본 교재와 문제 JSON이 바뀌지 않았는지 확인한다. 단위 검사와 브라우저 검사 후 커밋·main 푸시를 수행하고 같은 커밋의 Pages 배포와 공개 경로를 확인한다.

## 검증 완료 기준

- 교재 드롭다운 6권, 나머지 세 드롭다운과 전체 목록 각각 8주제. 추가 묶음 단계 없음.
- 600문항이 새 주제에 누락·중복 없이 한 번씩 배정. 전체 수와 주제별 수 일치.
- 저장된 정답 기록이 분리 후에도 집계되고, 한 주제 초기화가 다른 주제를 지우지 않음.
- 완료 히스토리에서 해당 문항으로 이동하고 모드 전환·새로고침·뒤로 가기에 주제 유지.
- 실무 관점 8페이지 × 10개, 총 80개. 제목·본문·예시·질문 TTS 사용 가능.
- 사례 11편의 본문과 근거 보존. 기존 주소와 새 주소 모두 사용 가능.
- 1440px·390px·320px 및 확대 화면에서 가로 넘침·잘린 메뉴 없음. 키보드로 메뉴 및 링크 이동 가능.
- 기존 교재 주소·페이지 앵커와 출제기준 링크 정상. 배포 완료 후 공개 사이트 재검사.

### 유지보수 기준

분류는 `shared/learning-subjects.mjs`, 사례별 배치는 `reading/case-subjects.mjs`, 실무 원고는 `practical/content.mjs` 및 `additional-content.mjs`에서 관리한다. 생성 HTML보다 원본을 먼저 수정한다. 향후 다른 주제의 사례를 추가하면 분류도 함께 등록한다. 현재 IT 비즈니스에 11편이 있고 나머지 사례 주제는 준비 중이다.
