# 교재 링크 통일

- 강의·핵심노트·사례·학습 문서의 교재 링크를 topcit2/textbook/번호/#page-NNN으로 통일한다. 기존 쪽 번호를 보존한다.
- 생성 원본과 검사 규칙을 함께 수정하고 교재 링크 이름에서 PDF를 제거한다. 교재 원문과 원본 파일은 변경하지 않는다.
- 생성 후 링크 대상 페이지, PC·모바일 이동, 강의·사례 검사를 실행하고 배포한다.

## 검증 결과

- 생성 원본과 생성 결과의 링크 848건, 서로 다른 교재 위치 165곳을 검사했다. 운영 콘텐츠의 예전 절대주소는 0건이다.
- 강의 3회차를 1440·768·390·320px에서 검사했다.
- 핵심노트 160개·사례 160개를 PC·모바일에서 확인하고 새 교재 20쪽 이동을 검증했다. 기존 사례 11편의 교재 링크 이동도 통과했다.
- 사례 스키마·교재 대응 단위 검사 7개 통과. 새 교재 이외의 예전 뷰어 링크는 사례 생성 단계에서 거부한다.
