# 수학·기술 표기 TTS 발음 개선

## 범위와 원칙

- 여섯 교재, 핵심노트, 문제은행의 실제 표기를 조사한다. 원문·정답·학습기록은 변경하지 않는다.
- 사용자 지정 발음은 유지한다: logn 로그엔, n 엔, nlogn 엔로그엔, n² 엔제곱, n³ 엔세제곱, 2ⁿ 이엔제곱.
- 거듭제곱·로그·분수·사칙연산·비교·집합·논리·단위·소수·백분율의 낭독용 전처리를 추가한다.
- HTML 위첨자·아래첨자를 일반 글자로 합쳐 읽는 문제는 DOM에서 의미를 추출하되 하이라이트의 원문 좌표를 유지해 해결한다. 각주를 지수로 바꾸지 않는다.
- URL·날짜·시간·IP/CIDR·버전·코드 식별자를 무조건 수식으로 바꾸지 않는다. 판단하기 어려운 식은 원문을 남긴다.

## 검증·공개

1. 공식 문서 조사와 실제 자료의 표기별 빈도·예시 기록.
2. 낭독 문자열과 오변환 방지 테스트, 실제 브라우저의 utterance·하이라이트·원문 보존 검사.
3. 기본 OFF·속도·일시정지·다시 읽기 등 기존 TTS 검사.
4. 커밋·푸시·공개 사이트 확인. 합성기에 전달한 문자열 검증과 사람이 실제 음성을 들은 평가는 구분한다.

## 완료 기록 · 2026-09-19

- 교재 6권·노트 8과목·문제 3,000개, 총 3,014개 원본 묶음을 조사했다. `tts-notation-audit.json`은 표기별 발생 횟수와 실제 예시를 기록한다. 발생 횟수는 오발음 개수가 아니다.
- `speech-math.mjs`에 빅오·로그 밑·거듭제곱·루트·팩토리얼·분수·산술·비교·집합·논리·화살표·소수·범위·백분율·시간/저장/전송 단위를 추가했다. 기술 약어 20개도 보강했다.
- 위·아래첨자를 읽을 때 원문 좌표를 유지한다. HTML 각주를 지수와 구분하고 코드 영역은 수학식으로 재해석하지 않는다. 모호한 식에는 작성자가 `data-tts-text`로 명시적인 낭독문을 지정할 수 있다.
- 단위·발음·생명주기 단위 검사 61개 통과. 1440·390px에서 실제 TTS 버튼을 눌러 위첨자·아래첨자·각주·코드·명시적 낭독문·사용자 지정 발음의 utterance와 하이라이트 원문을 확인했다.
- 기존 TTS OFF·범위·목차 제외·레이아웃·목록·토글·동적 문제·하이라이트·문맥 검사를 모두 확인했다. 하이라이트 검사의 원문/낭독문 직접 비교와 문맥 검사의 일반 버튼 선택을 바로잡았다. 화면 원문·복사 내용과 읽는 문장은 서로 구분해 검사한다.
- 한계: 실제 한국어 음성을 사람이 청취한 평가는 하지 않았다. 브라우저에 전달되는 낭독 문자열을 검증했다. 복잡한 중첩 수식·그림·MathML 전체의 의미 해석은 자동 보장하지 않으며 필요하면 명시적 낭독문을 사용한다. 비교·집합 기호는 수식을 자연어 문장으로 재작성하지 않고 기호의 뜻을 순서대로 읽는다.
