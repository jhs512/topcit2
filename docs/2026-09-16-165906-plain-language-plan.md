# 학생용 콘텐츠 전체 문장 명료화 계획

## 요청과 완료 기준

“시스템이 없어도 설명할 수 있는 사업 목표가 있습니까?”처럼 독자가 의도를 추측해야 하는 문장을 전체 학생용 콘텐츠에서 찾아 풀어 쓴다. 과목·특정 문장에 한정하지 않는다. 수정·생성·검증·커밋·푸시·공개 배포 확인까지 수행한다.

## 검토 범위

- 여덟 과목 핵심노트 160개: 제목, 설명, 가상 예시, 확인 질문, 과목 도입부.
- 교재 연결 설명과 추가 학습 질문: `shared/textbook-alignment.json`, `textbook-case-alignment.json`, `textbook-study-paths.json`.
- 사례 160편: 원본 `reading/expanded-cases.mjs`, `reading/it-business-stories.md`와 생성기의 교훈 표현.
- 문제은행 전체: 질문·선택지·해설. 정답의 근거와 오답 구분을 유지하고 편집 정책에 따라 수정한다.
- 홈·학습방법·시험 안내·출제기준·교재/문제/사례 목록·수업 3회차·강사소개·뷰어의 자체 안내 문구.
- 원본 교재 PDF와 전사본은 원문 보존 자료이므로 임의로 의역하지 않는다. 사이트에서 추가한 해설과 안내를 수정한다. 법령·공식 출제기준 인용과 고유명칭도 정확성을 보존한다.

## 수정 기준

1. 누가 무엇을 하는지 쓴다. “경계”, “책임”, “전환”, “연결”, “목표”만 남기지 않고 대상과 행동을 밝힌다.
2. 왜 그 행동이 필요한지 원인이나 상황을 먼저 설명한다.
3. 질문은 학생이 어떤 내용을 답해야 하는지 알 수 있게 쓴다. 기술 없이 목표를 말하라는 식의 생략은 실제 업무 개선 질문으로 바꾼다.
4. 전문용어는 유지하되 처음 접하는 학생이 이해할 수 있는 풀이를 붙인다. 정확한 기술적 차이를 없애지 않는다.
5. 가상 예시의 예상과 실제 결과를 구분한다. 원본 사례에 없는 사실이나 성과를 추가하지 않는다.
6. 제목·한 줄 교훈도 구체적으로 쓴다. 길이만 늘리거나 동일 문구를 기계적으로 덧붙이지 않는다.

## 작업 순서

1. 콘텐츠 원본과 생성 관계를 확인하고 전체 검토 목록을 만든다.
2. 과목별로 핵심노트와 교재 연결 내용을 읽고 문맥에 맞게 수정한다.
3. 전체 사례·문제은행·공통 안내를 읽고 같은 기준으로 수정한다.
4. 수정된 원본으로 정적 페이지를 다시 생성한다.
5. 문항 ID·정답·개정 정책·학습기록 호환, 과목별 개수·기존 주소·교재 링크를 확인한다.
6. 관련 자동 검사와 PC/모바일 화면·목차·TTS·문제 풀이를 검증한다.
7. 변경 범위를 확인하고 main에 커밋·푸시한 뒤 공개 페이지를 확인한다.

## 호환성과 검증

- 과목 ID, concept 앵커, 사례 ID, 문항 ID, 경로와 저장 키를 유지한다.
- 생성 HTML을 직접 고쳐 원본과 다르게 두지 않는다.
- 시험 일정이나 공식 규정을 바꾸게 되면 해당 공식 출처를 다시 확인한다.
- 검사: build:practical, build:cases, build:syllabus, lec/build, npm test, test:core, test:case-schema 및 영향받는 브라우저 검사.

## 진행 기록

- 전체 원본과 생성 관계 확인 완료. 핵심노트는 교재 대응 JSON의 보완 문장을 반영한 최종 출력 기준으로 검토했다.
- 핵심노트 160개를 검토하여 136개를 수정했다. 필드별로 제목 57개, 설명 46개, 예시 16개, 질문 121개이며 한 노트에 여러 변경이 포함될 수 있다.
- 사례 160편을 검토했다. 핵심노트 기반 원고 149편 중 36편의 상황·행동·결론을 수정했고, 기존 11편 중 8편을 수정했다. 노트 제목·원리와 교재 연결 설명도 생성된 사례에 반영했다.
- 문제은행 600문항의 핵심 개념 설명을 확인하고, 질문·보기·해설 전체에 모호한 축약 표현 검사를 적용했다. 후보 문장은 해당 문항의 맥락과 정답 근거를 확인해 수정했다. 총 94문항이 바뀌었다.
- 문제 ID·개정 번호·정답 위치·보기 순서·분류·출처는 전후 비교로 동일함을 확인했다. 4문항(biz4-059·247·294·295)의 보기는 의미를 유지하며 풀어 썼고, biz4-294의 질문도 ‘얻은 가치’를 ‘완료한 작업에 배정된 예산’으로 명시했다. 단순 표현 보완이므로 개정 번호와 학습기록을 유지한다.
- 여덟 과목 도입, 교재 연결 설명, 추가 학습 질문, 3회차 수업 자료, 학습방법, 교재 목록과 공통 과목 설명을 점검·수정했다. 홈·강사소개·뷰어·시험 안내는 확인한 자체 문구를 유지했다. 공식 출제기준과 시험 수치, 원본 교재 전사본은 의역하지 않았다.
- 기존 이야기의 사건·금액·출처 URL은 유지했다. `topcit/reading`의 동명 원고와 기획도 동기화했고 파일 내용이 같은지 확인했다.
