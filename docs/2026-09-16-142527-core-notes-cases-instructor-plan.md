# 핵심노트·사례 확장과 강사소개

작성: 2026-09-16 14:25:27 KST

## 완료 목표

- ‘실무 관점’의 학생 화면 이름을 ‘핵심노트’로 통일한다. 기존 주소와 노트 앵커는 유지한다.
- 여덟 주제별 노트 20개 이상, 사례 20편 이상을 제공한다. 목표는 각각 160개이며 기존 IT 비즈니스 사례 11편은 그대로 보존하고 9편만 보충한다. 나머지 7주제에는 20편씩 추가한다.
- 새 사례는 노트의 개념과 연결하되 상황·선택·결과·교훈이 있는 가상 사례로 명시한다. 실제 사건과 허구를 섞지 않는다.
- 제공된 이력서와 공개 활동 자료를 바탕으로 강사소개를 구성한다. 연락처·생년월일·성별·병역 등 소개에 불필요한 개인정보는 게시하지 않는다. 이력서 원본 전체도 저장소에 올리지 않는다.

## 순서

1. 이력서 및 공개 자료 조사. 프로필에 쓸 사실과 확인 범위를 별도 기록.
2. 메뉴·홈·정책·작성 지침의 이름과 수량 기준 변경.
3. 주제별 노트 열 개 추가. 기존 개념 번호 1~10 유지.
4. 기존 사례 보존 + 새 사례 149편. 노트 근거 링크를 스키마와 생성기에 추가하고 각 주제의 목록·이전/다음 이동 생성.
5. 강사소개 페이지 구성과 메뉴 연결.
6. 전체 수량·중복·근거 링크·기존 내용 보존·TTS·PC/모바일 검사. 커밋·푸시·Pages 확인.

## 품질 기준

노트의 설명과 예시가 중복되지 않게 주제를 구분한다. 각 사례는 고유한 제목, 구체적 선택과 결과, 별도의 결론을 갖춘다. 새 사례의 원리는 공식 교재 인용이 아니라 연결된 핵심노트의 자체 해설임을 표시한다. 출처에서 확인하지 못한 경력은 공개 검증을 받은 것처럼 서술하지 않는다.
