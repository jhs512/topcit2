장애 때 재시도가 요청을 더 늘렸다

가상 이야기 · 핵심노트 기반

핵심노트 개념: 과부하 제어 — 모든 요청을 받다가 모두 실패하지 않는다

이 글에서 배우는 교훈

처리 능력을 넘는 요청을 계속 받으면 대기와 자원 소진으로 전체가 느려질 수 있습니다.

핵심노트를 바탕으로 만든 가상 이야기입니다. 실제 사건이나 검증된 성과가 아닙니다.
근거: 과부하 제어 — 모든 요청을 받다가 모두 실패하지 않는다 · 핵심노트 14

구체적으로는 팀은 재시도 간격과 횟수를 제한했습니다.

본문

외부 조회가 느려지자 여러 서비스가 즉시 재시도했습니다. 이미 과부하인 외부 서비스에 요청이 더 몰려 회복이 늦어졌습니다.

팀은 재시도 간격과 횟수를 제한했습니다. 혼잡 시 일부 요청을 보류하고 사용자에게 재시도 가능한 시점을 안내했습니다.

결론

재시도는 실패를 숨기는 무제한 반복이 아니었습니다. 상대 시스템의 회복과 전체 부하를 고려해 제한해야 합니다.
