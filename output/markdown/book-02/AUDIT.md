# 교재 02 변환 검수 기록

- 원본: 데이터 이해와 활용, PDF 159쪽.
- 범위: PDF 001–159 전체. 빈 페이지 002·159도 경계 주석으로 보존.
- 산출물: `pages/page-NNN.md` 159개와 페이지 순서대로 합친 `book.md`.
- 상태: 전 페이지 변환과 전 페이지 시각적 구조 대조를 마쳤다. 아래 한계가 있는 OCR 기반 검수본이다.

## 실제 수행한 확인

원본의 한글 텍스트 레이어가 손상되어, PDF의 원본 페이지 래스터에 한국어 OCR을 다시 수행했다. 원본 페이지 001–159를 4쪽 묶음으로 모두 열어 문단·표·그림 위치와 변환 구조를 확인했다. 식별자, 정규화, 관계대수, SQL, 트랜잭션, 빅데이터 등 오인식이 집중된 페이지는 확대 원본을 추가로 열어 본문·수식·예제 표를 재작성했다. 원형 숫자 항목은 원본 기호의 이미지 대조를 활용하여 교정했다.

문법 검사에서 159쪽의 페이지 번호와 페이지 파일 존재를 확인했고, HTML 표의 열 수 및 rowspan/colspan 충돌을 검사했다. 원본 이미지·연락처·이메일·직접 PDF 링크는 결과물에 넣지 않았다. 실제 실행하지 않은 SQL·C 예제를 실행 검증했다고 표시하지 않는다.

## 보존 및 생략 방식

본문과 표는 요약하지 않고 옮겼다. 여러 엔터티 관계선, 화살표, 사진, 그래프, 신경망 그림 등 충실한 텍스트 표현이 어려운 그림은 해당 위치에 구체적인 HTML 생략 주석을 남겼다. 그림 안의 정규화 예제 데이터 표와 SQL 구문은 별도로 보존했다. 관계가 명확한 일부 순서도만 Mermaid로 표현했다. 이러한 생략은 상위 CONVERSION-RULES.md의 그림 처리 기준에 따른다.

원본 자체의 오기·불완전한 구문을 임의로 정정하지 않은 부분이 있다. 예를 들어 PDF 073의 예제 열 이름, 077의 P2 값, 107의 GROPU BY 설명, 114의 SQR, 115의 C·임베디드 SQL 코드는 원문 표기를 유지한다. PDF 066의 외래키 Null 설명 등 원문 자체의 내용상 오류도 교정판으로 바꾸지 않았다.

## 한계

전 페이지 시각적 구조 대조와 발견된 오인식 교정은 수행했지만, 모든 문자를 사람의 전사본과 자동 비교한 것은 아니다. 영문 철자·띄어쓰기·문장부호의 미세한 OCR 오차가 남을 수 있다. 복잡한 그림의 원래 도형·공간 배치·관계선은 생략되므로 원본 PDF와 시각적으로 동일한 복제본은 아니다. 통합 검증에서 HTML 리더 159쪽·표 138개와 Mermaid 5개의 실제 렌더링을 확인했다.

## 재생성

배포본의 수정 원본은 `pages/page-NNN.md`이며, `book.md`는 페이지 번호순으로 연결한 합본이다. 변환 도구·OCR·검수 이미지는 로컬 작업 자료로 배포 대상에서 제외했다.
