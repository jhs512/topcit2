# 소프트웨어 개발 전사 검수 기록

- 원본: sources/01_소프트웨어_개발.pdf, 실제139쪽.
- 전체139쪽에 대해 원본 페이지와 본문을 대조했다. 001~016쪽은 연락처·목차 검수를 포함한 묶음 이미지 및 필요한 개별 확대, 017~139쪽은 개별 원본 이미지로 확인했다.
- 원본의 기존 텍스트층은 심하게 손상되어 사용하지 않고, 원본 내장 래스터를 Windows 한국어 OCR로 재인식한 뒤 대조·교정했다. 내장 이미지 없는 빈 페이지는 PDF 렌더로 확인했다.
- OCR 오인식, 영문 용어, 수식, 코드, 제목 계층, 목록, 목차 쪽수, 표의 행·열과 병합셀을 교정했다.
- 모든 페이지 번호001~139가 한 번씩 있으며, 합본은 개별 페이지의 번호순 단순 연결이다. H1은1개, Mermaid27개, HTML표53개이다. Markdown표를 포함한 리더의 전체표는83개이다.
- 코드 및 내용의 원본 오류는 임의로 고치지 않았다. 예: 원본의 Prime, Fibinacci, Collective, Real Eval Print Loop 표기와 잘못된 예제 코드도 보존했다.
- 연락처, 반복 인쇄 머리말·꼬리말, 장식은 전사 규칙에 따라 제외했다. 이미지 삽입은0개이다.

## 도식의 한계

- 원본 노드·문구·관계를 확인한 도식은 Mermaid로 전사했다. 시각적 위치와 모양은 원본과 다를 수 있다.
- 039쪽 스택 도식의 곡선 화살표, 050쪽 탐색 트리의 겹친 순회 화살표 등 Mermaid로 정확히 재현하지 않은 시각 요소는 해당 위치의 HTML 주석에 기록했다.
- 113쪽 문장 추적 사례는 원본에서도 문서 속 문장을 읽을 수 없다. 네 문서의 제목은 보존하고 내부 문장·연결은 임의 추정하지 않았으며 생략 주석을 남겼다.
- 전체 본문은 원본대조 전사이며, 원본의 기술적 사실·시의성을 새로 검증하거나 개정한 교재가 아니다.

## 구조·렌더 검증

- 139개 페이지의 첫줄 표식, 코드펜스 짝, HTML표의 rowspan/colspan 반영 열 수를 검사하여 오류0건을 확인했다.
- Mermaid12.0.0으로27개 도식 전부 파싱 및 실제 SVG 생성 성공.
- 공통 HTML리더에서139쪽·표83개·도식27개를 로드하고 JavaScript 실행오류0건을 확인했다. 094쪽 표를 포함한 실제 리더 스크린샷을 확인했다.
- 원본의 모든 페이지는 대조했으나, 모든 HTML페이지의 스크린샷을 별도로 검수한 것은 아니다.

## 재현 및 중간 산출물

- ocr.ps1: 원본PNG 폴더를 Windows OCR JSON으로 변환. 다른 권에서도 공용 사용한다.
- build-pages.py: 최초 초안 생성용. 수동 교정 후 재실행하면 교정 내용을 덮어쓰므로 실행하지 않는다.
- correct-*.py: 작업 중 사용한 교정 기록. 일부는 초안을 대상으로 하므로 재실행하지 않는다.
- check-structure.py, check-render.cjs, check-reader.cjs: 구조와 렌더 검증.
- 원본PNG·OCR JSON 및 검증 스크린샷은 tmp/book01 아래에 있으며 배포 대상이 아니다.
- 개별 pages/page-NNN.md가 수정 원본이다. book.md는 번호순으로 다시 병합한다.
