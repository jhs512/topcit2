# 원문 대조 및 뷰어 검수

PDF 실제 213쪽과 페이지별 Markdown을 다시 대조했다. 최초 변환본에는 내용 누락과 도식 관계 오류가 있었으며, 이번 재감사에서 발견한 확정 오류를 수정했다.

## 주요 수정

- 26쪽: 가치사슬 지원활동 설명의 빠진 문장 말미 복원.
- 38쪽: SWOT 분석의 전략적 방향성 설명 누락 복원.
- 32·43·88·101·123·141·147·186·189쪽: 도식 방향이나 공통 연결, 반환 범위 교정.
- 37·121쪽: 추정된 도식 관계를 제거하고 원문 노드/문구를 표로 보존. 복잡한 연결 배치는 생략 표시.
- 149쪽: 학생·교사·학교의 점선 연결 9개 복원.
- 46·167·169쪽: 원문의 병합 셀 범위 복원.
- 66쪽: 표 뒤에 중복으로 남은 OCR 문구 제거.
- 71·179쪽: 도식 영역 표기와 표제 복원.
- 기타: 경쟁력, 절차, 공동 행동의, A업무, 송도서, KISA 등 오인식과 목록·문단 경계 교정.

## 검사 결과

- 213개 페이지와 합본 페이지 순서/누락 검사.
- Markdown 표 159개, HTML 표 23개의 열 수와 병합 셀 범위 검사.
- Mermaid 44개 실제 파서 문법 검사.
- 제목 단계 건너뛰기, 중복 HTML 앵커 검사.
- 뷰어의 본문 로딩, 목차, 검색, 표 확대/복원, 테마, 페이지 이동 기능 검사.

## 범위와 한계

- 장식, 사진, 표현하기 어려운 곡선·공간 배치는 요청에 따라 생략했다. 모든 시각 정보를 보존한 복제본은 아니다.
- 원문 자체의 오탈자, 중복 장번호와 과거 시점의 법령·수치는 임의로 개정하지 않았다.
- 원본 열람 링크, 연락처 및 예시 식별번호의 기존 생략을 유지했다. 일부 참고문헌 URL도 이전 전사 단계에서 생략되어 있으므로 URL 문자열까지 완전히 동일한 전사본은 아니다.
- 모든 페이지를 대조했지만 문장부호와 미세한 띄어쓰기까지 무오류임을 보증하지 않는다. 확인한 내용 오류는 수정했다.

## 읽기 화면

[전용 HTML 뷰어](index.html)는 합본 Markdown을 읽고 PDF 페이지 주석을 기준으로 나눈다. 편집 원본은 계속 페이지별 Markdown이며, 합본은 merge-pages.py로 생성한다.

[Marked](https://marked.js.org/)로 Markdown을 파싱하고, [DOMPurify](https://github.com/cure53/DOMPurify)로 HTML을 정제하며, [Mermaid](https://mermaid.js.org/config/usage.html)로 도식을 표시한다. 라이브러리는 버전이 고정된 CDN에서 읽는다.
