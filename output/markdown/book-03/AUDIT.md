# 시스템아키텍처 이해와 활용 전사 검수

- 실제 PDF 221쪽 전체를 변환하고 원본과 대조했다. 1–170쪽은 주 담당의 페이지별 검수, 171–210쪽은 지원 담당의 원본 대조, 211–220쪽은 통합 담당의 개별 이미지 대조로 본문·표·도식·기술 용어를 교정했다. 2·221쪽은 빈 쪽으로 보존했다.
- 원본의 훼손된 문자층 대신 한국어 OCR 초안을 만든 뒤 교정했다. 수정 원본은 `pages/page-NNN.md`, 합본은 번호순으로 연결한 `book.md`이다. OCR·원본 이미지·작업 스크립트는 로컬 자료로 배포에서 제외했다.
- Mermaid 74개를 실제 SVG로 생성하여 확인했다. 48쪽의 깨진 중복 도식을 제거했다. HTML 표 구조와 페이지 표식 검사에서 오류가 없었다. 공통 리더에서 221쪽·표 200개를 로드하고 검색·마지막 페이지 이동·모바일 화면을 확인했다.
- 26쪽 그림 2 하단의 두 공통 연결선을 원본과 추가 대조했다. 원본에 표시되지 않은 스위치와 하단 선 사이 연결은 추정하지 않았다.
- 38쪽 그리스어 글리프는 확정할 수 없어 `[판독 불가]`로 유지했다. 바로 뒤의 로마자 표기 isos는 보존했다.
- 복잡한 공간 배치·곡선·화면 이미지는 생략 주석을 남기고 확인 가능한 라벨과 수치를 전사했다. 원본과 시각적으로 동일한 복제본이 아니다.
- 원문의 과거 기준과 자체 오류는 임의로 갱신하지 않았다. 모든 페이지 대조를 수행했지만 모든 글자·문장부호까지 무오류임을 보증하는 축자 교정은 아니며 미세한 OCR 오류가 남을 수 있다.
