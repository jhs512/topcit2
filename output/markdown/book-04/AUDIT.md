# 04 정보보안 이해와 활용 변환 검수

- 원본 PDF 124쪽을 각각 원본 이미지 또는 PDF 렌더와 대조했다. 빈 페이지도 페이지 표식을 보존했다.
- 본문·목차·표·코드의 OCR 오류를 교정했으며 수정본은 overrides/, 페이지별 확인 기록은 reviewed.json에 저장한다.
- 표는 Markdown 또는 병합 셀을 가진 HTML로, 관계가 확인되는 도식은 Mermaid로 옮겼다. 화면 캡처·복잡한 그림·장식은 변환 규칙에 따라 HTML 주석으로 생략을 표시했다. 원본 이미지 자체를 보존한 복제본은 아니다.
- 코드와 과거 표준·기술 설명의 원본 오류는 임의로 현대화하거나 수정하지 않았다. 코드 예제의 실행 가능성을 검증한 문서가 아니다.
- 육안 교정으로 모든 미세한 문자·기호 오류가 없음을 보증하지 않는다. 통합 검증에서 HTML 리더 124쪽·표 58개와 Mermaid 56개의 실제 렌더링을 확인했다.
