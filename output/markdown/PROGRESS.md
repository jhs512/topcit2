# 6권 웹 교재 변환 기록

6권의 실제 PDF 페이지 총 995쪽을 페이지별 읽기 자료로 연결한다. OCR 초안 생성만으로 완료 처리하지 않고 원본 대조와 HTML 읽기 화면 검증을 수행했다.

| --- | ---: | --- |

| 06 프로젝트관리 및 테크니컬커뮤니케이션 | 139 | 전체 |

각 권의 `pages/page-NNN.md`가 수정 원본이며 합본은 페이지 순서대로 연결한다. 새로 변환한 교재의 대조 범위와 한계는 각 `book-XX/AUDIT.md`에 기록했다. 원본 렌더·OCR·작업 스크립트는 로컬 작업 자료로 배포하지 않는다.

본문·표와 관계를 확인한 도식을 옮겼으며, 복잡한 이미지와 화면 캡처는 생략 주석으로 표시했다. 따라서 원본 PDF와 시각적으로 동일한 복제본은 아니다. 원문의 과거 기준과 자체 오류는 임의로 갱신하지 않았으며 미세한 OCR 오류가 남을 수 있다.
