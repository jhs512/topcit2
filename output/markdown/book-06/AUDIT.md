# 변환 검수 기록

- 대상: 프로젝트관리 및 테크니컬커뮤니케이션 PDF 전체 139쪽. 페이지 표식과 순서를 유지했다.
- 1–70쪽은 전체 묶음 이미지 비교와 필요한 확대 확인, 71–139쪽은 개별 원본 이미지 비교로 본문·표·수식·도형 라벨을 교정했다. 빈 쪽도 페이지 표식을 유지했다.
- 표의 셀 대응과 병합 구조를 복구했으며 HTML 표 구조 검사를 통과했다. 관계가 확인되는 흐름도는 Mermaid로 옮겼다.
- 복잡한 화면 캡처·곡선·그림은 생략 주석을 남겼다. 확인 가능한 수치와 라벨은 표 또는 본문으로 옮겼다. 원본 이미지와 동일한 외형을 재현한 문서는 아니다.
- 원문의 오래된 기준, 수치·설명 간 모순 및 인쇄 오류는 임의로 갱신하지 않았다. 예를 들어 64쪽 범례와 본문의 비율 차이, 120쪽 `40$` 표기는 원본대로 남겼다.
- 이 검수는 모든 페이지의 구조·문맥 및 발견된 OCR 오류 교정이다. 모든 글자의 띄어쓰기·문장부호까지 무오류를 보증하는 축자 교정은 아니다.
- 통합 검증에서 HTML 리더 139쪽·표 112개와 Mermaid 17개의 실제 렌더링을 확인했다. 페이지 표식·표 구조·중복 제목·브라우저 실행 오류는 없었다.
