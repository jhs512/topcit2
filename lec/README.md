# 회차별 수업 자료 유지보수

- 2026-09-16, 09-17, 09-23 수업 전용. 시간은 모두 한국 시간 18:00–20:00이다.
- `content.mjs`에서 진행 계획·요약·자료 링크를 편집하고 `node lec/build.mjs`로 페이지를 생성한다.
- 다른 페이지·자료로 이동하는 링크는 `target="_blank" rel="noopener noreferrer"`로 연다. 생성기가 자료 링크와 본문의 `data-page-links="new-tab"` 설정을 적용하고, 공통 메뉴는 이 설정이 있는 페이지에서만 새 탭을 사용한다. 페이지 내부 목차·본문 바로가기와 댓글 새로고침·TTS 같은 버튼 동작은 유지한다.
- 기존 홈·메뉴·학습 페이지에서 이 디렉터리를 참조하거나 링크하지 않는다. 이곳에서 기존 자료로 가는 단방향 링크만 제공한다. 수업 페이지 간 이동 링크도 만들지 않는다.
- 각 페이지의 검색 제외 메타 태그는 검색 노출을 줄이는 설정이며 접근 통제가 아니다. 사이트와 저장소는 공개 상태다.
- `issues.json`은 회차별 댓글 공간을 가리킨다. Utterances 댓글창을 해당 이슈 번호에 연결해 페이지 하단에서 조회·작성한다. 로그인은 Utterances의 GitHub 인증 흐름으로 처리하며, 사이트 코드에 토큰을 넣지 않는다. 저장소에 Utterances GitHub App을 설치해야 한다.
- `comments.mjs`는 Utterances 작성창을 불러오고, 실패하면 보조 조회 영역을 연다. 보조 조회는 댓글을 일반 텍스트로 표시한다. 외부 응답의 HTML은 실행하지 않는다. 조회 제한·오프라인일 때도 GitHub 작성 링크는 유지한다.
- 수업 중 10분 휴식을 포함한 총 120분 계획이다. 네 주제를 다루는 1회차는 핵심 이해와 복습 안내를 중심으로 구성했다.
- 검증: `node lec/test.mjs`. 공개 검증은 `SITE_BASE`를 사이트 루트로 지정한다. 테스트 댓글은 실제 GitHub에 게시하지 않고 브라우저 응답을 대체하여 표시·오류·추가 조회를 검사한다.

## 연결 근거

교재 목차·학습목표와 해당 도입 본문을 확인했다. 확인한 도입 페이지는 03의 PDF 22쪽, 04의 14쪽, 05·06의 16쪽이다. 세부 단원 위치를 지정하지 않은 링크는 교재 시작 위치로 연결하고 목차에서 찾도록 설명한다. 핵심노트·사례는 사이트의 자체 해설로 구분한다.

댓글 조회는 [GitHub 공식 Issue comments API](https://docs.github.com/en/rest/issues/comments#list-issue-comments)를 사용한다. 댓글 작성은 [Utterances 공식 위젯](https://utteranc.es/)을 사용한다. GitHub 로그인 후 수업 페이지 하단에서 작성하며, 기존 이슈 1·2·3과 댓글을 유지한다.
