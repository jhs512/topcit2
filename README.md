원본 교재와 텍스트 서재를 모은 독립 저장소입니다. 보관본을 최신 개정판으로 표시하지 않습니다. 교재의 저작권은 원저작권자에게 있습니다.

## 열람

저장소 폴더에서 `python -m http.server 4173`을 실행한 뒤 [교재 서재](http://localhost:4173/)를 엽니다. 위의 HTML 링크는 웹서버에서 열 때 동작합니다. GitHub 파일 화면은 뷰어를 실행하지 않습니다.

## 유지보수

`viewer/`는 PDF 뷰어, `sources/`는 PDF 6권, `output/markdown/`은 전사본·공통 서재·대조 기록입니다. 원본 `jhs512/topcit`에서 교재 관련 파일만 복사했습니다. 원본 저장소는 변경하지 않았습니다.

## 선택 기능: 사이트 공통 TTS (기본 꺼짐)

모든 페이지의 공통 상단에 **TTS 꺼짐 / TTS 켜짐** 버튼이 있습니다. 첫 방문은 꺼짐이며, 켜면 본문의 읽기 버튼이 나타납니다. 실제 낭독은 개별 읽기 버튼을 눌러야 시작합니다. 상단에서 끄면 재생을 취소하고 우측 하단 패널·읽기 버튼·강조 표시를 정리합니다.

선택은 이 브라우저의 `localStorage` 키 **`topcit2:tts-enabled`**에 저장되어 새로고침·사이트 이동과 같은 출처의 다른 탭에 반영됩니다. 저장소를 사용할 수 없으면 현재 페이지에서만 선택을 유지합니다. `shared/site-features.mjs`의 **`defaultTtsEnabled = false`**는 저장된 선택이 없는 첫 방문의 기본값이며 사용자 ON을 막는 운영 차단 설정이 아닙니다. 이전 `enableTts` 플래그는 제거했습니다.

처음 OFF인 페이지에서는 작은 loader와 기본 설정만 읽고 음성 엔진·CSS·읽기 UI는 불러오지 않습니다. 최초 ON에서 지연 로드하고, OFF에서는 관측기·이벤트·예약된 화면 갱신까지 정리합니다. 이미 요청한 모듈 다운로드는 완료될 수 있지만 OFF이면 초기화하지 않습니다. 다시 켜면 중복 없이 새 읽기 UI를 구성합니다.

읽기 대상은 교육 콘텐츠 영역(`data-tts-content`) 안에서 `tts-readable`을 지정한 요소뿐입니다. 교재 본문·문맥 속 절 제목, 문제 지문·보기·공개 해설, 사례의 교훈·도입·서사·결론에 표시합니다. 히어로·브랜딩·목차·카드·이동 유도·조작 안내·시험 일정·이용 안내·출처 표시는 제외합니다. 페이지 전체에 자동 부여하지 않고 교육 콘텐츠를 생성하는 렌더러에서만 명시합니다.

```html
<section data-tts-content>
  <p class="tts-readable">학습 내용인 이 문단을 읽습니다.</p>
</section>
```

`data-tts-exclude`는 교육 영역보다 우선하는 낭독 제외 표시입니다. 목차 페이지 전체와 목차 표에 적용해 제목·표 머리글·항목·쪽수와 확대창으로 이동한 표까지 제외합니다. 6권의 실제 목차 범위는 `output/markdown/book-speech-policy.mjs`에 기록하고, 원본 Markdown의 모든 목차 표와 대조합니다. `startPage`나 단일 단어만으로 목차를 판단하지 않습니다.

부모·자식에 모두 지정하면 부모 하나만 버튼을 받습니다. 숨겨진 요소와 자손(`hidden`, `aria-hidden`, CSS 숨김), 내비게이션·폼 컨트롤·버튼·출처 링크 문구·URL은 읽지 않습니다. 링크/버튼 안의 마커는 건너뜁니다. 보기 텍스트는 별도 `tts-option` 감싸기 안에 표시하고 읽기 버튼을 라디오 label 밖에 붙여 선택과 충돌하지 않게 합니다. 교재 렌더러는 본문·표·목록의 의미 단위에 클래스를 부여합니다. PDF 캔버스 같은 이미지 자체는 낭독 대상 텍스트가 아닙니다.

발화가 시작되면 현재 읽는 문장 범위를 강조합니다. 우측 하단 패널에 이전 문장·현재 읽는 문장·다음 문장을 표시하며, 긴 문장이 여러 발화 조각으로 나뉘어도 원문 문장 전체의 강조와 앞뒤 문맥을 유지합니다. 현재 블록의 낭독 대상 텍스트만 표시하며, 긴 문맥은 패널 안에서 스크롤할 수 있습니다. 일시정지 중에는 위치를 유지하고 정지·종료·TTS 끄기·내용 변경·페이지 이동 시 해제합니다. 원본 DOM과 링크 이벤트를 유지하는 CSS Highlight API를 사용하며, 미지원 브라우저는 Range 좌표 표시로 대체합니다. 자동 스크롤은 하지 않습니다.

동적 삽입·교재/문제 전환·공개 해설·숨김/내용 변경을 반영하며, 읽던 요소가 사라지거나 내용이 바뀌면 이전 재생을 중단합니다. 변경된 DOM 가지를 묶어 처리하고 자체 버튼 삽입 동안 관측을 멈춰 반복 삽입을 방지합니다. 재생·일시정지 중에는 화면 우측 하단의 작은 고정 nonmodal 레이어를 표시합니다. 닫기·정지·레이어 안 Esc는 재생을 멈추고 가능한 경우 원래 버튼으로 포커스를 돌려줍니다. 이어읽기는 멈춘 문장부터, 속도 변경은 다음 문장부터 적용됩니다. 선택한 속도는 로컬 스토리지에 저장되어 새로고침·페이지 이동·TTS 재활성화 후에도 유지됩니다. 저장값이 없거나 잘못되었으면 1배로 시작합니다. 한국어 음성과 기기별 성능 차이는 그대로이며 외부 유료 서비스는 사용하지 않습니다.

`npm run test:speech`는 분할·상태 검사를 실행합니다. 로컬 4186 서버에서 `npm run test:speech-feature`는 새 브라우저 프로필의 기본 OFF, ON→OFF→재ON, 저장·다중 탭 동기화, 비동기 로드 중 OFF, 모의 음성을 이용한 전체 페이지·동적 문제·숨김·우측 하단 패널을 검사합니다. 저장소 파일이나 기본값을 바꾸지 않습니다. `SITE_BASE`를 지정하면 공개 사이트에서도 같은 검사를 실행합니다. 공개 OFF 검사는 `SITE_BASE`에 공개 주소를 지정해 `npm run test:speech-disabled`를 실행합니다. 실제 오디오 청취는 모의/API 이벤트 검사와 별개입니다.

## 출제기준 복사본

[출제기준 V4.0K](syllabus/)는 2026-09-16 공식 사이트에서 가져온 4개 평가영역 전체입니다. 번호와 문장은 `syllabus/data.json`에 보관하고 `node scripts/build-syllabus.mjs`로 페이지를 생성합니다. 이후 개정은 자동 반영되지 않습니다. 출제기준을 링크할 때는 자체 복사본을 사용하며, 특정 항목은 `https://jhs512.github.io/topcit2/syllabus/#ref-4.2.2.2`처럼 연결합니다. 원본 출처는 복사본 페이지에서 확인할 수 있습니다.

핵심노트 기반 새 사례의 편집 원본은 `reading/expanded-cases.mjs`입니다. `npm run build:cases`가 `reading/cases/`의 Markdown과 `cases/`의 페이지를 함께 생성합니다. 기존 11편의 원본은 `reading/it-business-stories.md`로 유지합니다.


## 핵심노트·사례의 교재 근거

핵심노트의 교재 원개념과 항목별 근거는 `shared/textbook-alignment.json`, 기존 비즈니스 11편의 개별 근거는 `shared/textbook-case-alignment.json`, 추가 학습 설명·질문은 `shared/textbook-study-paths.json`에서 관리합니다. 기존 제목·예시·질문 원본과 결합해 `practical/content.mjs`가 최종 노트를 구성합니다. 대응 내용을 수정한 뒤 `npm run build:practical`과 `npm run build:cases`를 모두 실행합니다. 생성기는 모든 근거 페이지의 실제 존재와 대응 누락을 먼저 검사합니다.

[320개 항목 점검표](docs/textbook-alignment-audit.md)에 단원·쪽·연결 이유·본문 보강과 대표 수정 전후를 기록했습니다. 기준 원본의 목차·학습목표·관련 본문을 읽어 대조했으며, 20개 노트를 교재 전체 요약이나 시험 중요도 순위로 보지 않습니다. `node --test tests/textbook-alignment.test.mjs`로 대응·원문 페이지·학생용 생성 내용을 검사하고 `node tests/textbook-references.mjs`로 PC·모바일 전체 항목 표시와 공개 PDF 링크를 확인합니다. 점검표를 다시 만들 때는 기준 교재 저장소와 비교 커밋을 확인한 뒤 `node scripts/build-textbook-audit.mjs`를 실행합니다.
