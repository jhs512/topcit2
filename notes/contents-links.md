# 목차 표 이동 근거

## 페이지 대응

2026-09-15 저장소 `sources/`의 PDF 6권과 변환본의 교재 페이지 마커를 대조했습니다. 6권 모두 20쪽의 원본 하단에 인쇄 쪽수 18이 표시됩니다. 따라서 현재 보관본의 대응은 `교재 페이지 = 목차의 인쇄 쪽수 + 2`입니다. 다른 개정판으로 원본을 교체할 때는 이 대응을 다시 확인해야 합니다.

교재 02 19쪽 목차와 147쪽 본문은 원본을 렌더링하여 시각적으로 확인했습니다.

- [교재 02 19쪽 목차](https://jhs512.github.io/topcit2/textbook/02/#page-019): NoSQL의 BASE 속성 145쪽, 인공지능 이해 148쪽.
- [교재 02 147쪽 본문](https://jhs512.github.io/topcit2/textbook/02/#page-147): NoSQL의 BASE 속성 제목, 하단 인쇄 쪽수 145.
- [교재 02 150쪽](https://jhs512.github.io/topcit2/textbook/02/#page-150): 변환본의 `XV. 인공지능 이해` 제목 위치.

## 적용 범위

공통 `contents-links.mjs`는 본문 시작 전 페이지에 있고, 열 제목이 `목차`와 `교재 쪽수`/`책 쪽수`/`쪽`인 2열 표만 처리합니다. 숫자 쪽수와 실제 대상 페이지가 있는 행만 연결합니다. 같은 페이지에서 제목이 일치하면 제목 앵커로, 일치하는 제목이 없으면 해당 교재 페이지 시작으로 이동합니다. 본문 표와 숫자가 없는 목차 표지 행은 제외합니다.

각 셀 안에 실제 링크를 넣어 항목과 쪽수 모두 클릭·키보드 이동을 지원합니다. 원래 강조 서식과 표 확대는 유지합니다. 확대 창에서 링크를 선택하면 창을 닫고 본문으로 이동하며 기존 위치 저장 기능을 사용합니다.
